# QuizGameProject

A console-based math quiz game written in C++.

## Features
- Choose the number of questions
- Choose the difficulty level: Easy, Medium, Hard, or Mix
- Choose the operation: Addition, Subtraction, Multiplication, Division, or Mix
- Instant feedback after each answer
- Final summary showing all questions, your answers, and a Pass/Fail result
- Option to play again

## How to Run
1. Open `QuizGameProject.sln` in Visual Studio.
2. Press `Ctrl + F5` to build and run.

## Concepts Used
- `enum class`, `struct`, and `vector`
- Functions and code organization
- Random number generation
- Input validation
